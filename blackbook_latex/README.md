# Folium blackbook (LaTeX)

The project report in the college (SPIT) blackbook format.

## Compile

- **Overleaf:** upload this folder (or the zip), set the main file to `report.tex`, compiler pdfLaTeX, and compile.
- **Locally:** run `pdflatex report.tex` twice (the second run fills in the contents, lists and cross-references).

## Before printing, fill in

At the top of `report.tex`:

```latex
\newcommand{\rollJesil}{[UID No.]}
\newcommand{\rollParam}{[UID No.]}
\newcommand{\rollHet}{[UID No.]}
\newcommand{\submissionmonth}{[Month Year]}
```

Then replace the six screenshot boxes in Section 7.6 (`results.tex`, the `\screenshot{...}` lines) with
`\includegraphics` of real screenshots from the running app. Chapter 10 (`research_publication.tex`) is
intentionally empty, ready for the publication details.

## Files

| File | Contents |
|---|---|
| `report.tex` | Main file (packages, page set-up, order of chapters) |
| `be_title.tex`, `be_certificate1.tex`, `be_certificate2.tex`, `students_statement.tex`, `acknowledgments.tex`, `abstract.tex`, `list_abbreviations.tex` | Front matter |
| `introduction.tex` ... `conclusion.tex` | Chapters 1 to 9 |
| `bibliography.tex` | References |
| `research_publication.tex` | Chapter 10, Publications (empty for now) |
| `figures/tikz/` | All design diagrams, drawn in TikZ (`styles.tex` holds the shared style) |
| `figures/charts/` | Result charts as vector PDFs, generated by `make_charts.py` from the evaluation files in `results/` |

To regenerate the charts after re-running the evaluations: `python blackbook_latex/make_charts.py` from the repository root.
